
# ResearchAi – AI-Based Research Paper Analysis System

## Project Description
ResearchAi is a web-based application that uses Google Gemini AI to analyze research papers in PDF format.

## Features
- User Registration and Login
- Upload Research Papers in PDF format
- AI-Based Research Paper Analysis
- Research Domain and Objective Identification
- Methodology and Key Findings
- Strengths and Limitations
- Keyword Extraction
- Ask AI Questions Based on Research Papers
- Download Analysis Report as PDF
- Analysis History

## Technologies Used
- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript
- SQLite
- PyPDF2
- ReportLab

## Installation
1. Clone the repository.
2. Install required packages:
   pip install -r requirements.txt
3. Configure your Gemini API key in the .env file.
4. Run the application:
   python app.py
